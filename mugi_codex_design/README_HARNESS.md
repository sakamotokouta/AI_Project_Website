# Codex harness package

This folder contains the AI-facing implementation specification for the Boulangerie Mugi no Akari project.

## Copy into the repository

Copy these items to the repository root:

- `AGENTS.md`
- `CODEX_INITIAL_PROMPT.md`
- `CODEX_EXECUTION_PROMPTS.md`
- `docs/`

Then use the contents of `CODEX_INITIAL_PROMPT.md` for a full implementation, or choose a task prompt from `CODEX_EXECUTION_PROMPTS.md` for an existing project.

The Japanese developer documents are intentionally kept in a separate package and should not be copied into the repository unless desired.
